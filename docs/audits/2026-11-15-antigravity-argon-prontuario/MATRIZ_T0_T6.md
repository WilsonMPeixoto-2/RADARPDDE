## 1. Legenda dos 7 Níveis de Validação (Seção 9)

- **Nível 1:** Estático, sintaxe, lint (`eslint`, `stylelint`), contratos (`check:functional-matrix`), fronteiras arquiteturais (`depcruise`) e alinhamento Supabase (`check:supabase-final`, `typecheck:database`).
- **Nível 2:** Testes unitários Node.js (`npm run test:unit`).
- **Nível 3:** Testes de integração Node.js (`npm run test:integration`).
- **Nível 4:** Banco descartável / pgTAP (`supabase/tests/database/operational-correction.test.sql`).

- **Nível 7:** Inspeção visual de layout, responsividade (390 px, 1280 px, 1440 px, 1920 px), contraste AA (claro/escuro) e acessibilidade por teclado.
